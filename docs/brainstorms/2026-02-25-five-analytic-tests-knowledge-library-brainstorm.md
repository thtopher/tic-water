# 5 Analytic Tests — Price Transparency Knowledge Library Piece

## What We're Building

A companion piece to the Data Treatment Process artifact, covering the 5 analytic test scenarios that demonstrate Third Horizon's data quality and credibility in healthcare price transparency. Two deliverables from one codebase: an interactive HTML presentation for live show-and-tells, and a print/PDF version for leave-behinds. Part of the broader Starset sales enablement suite and MMA's knowledge library.

## Why This Approach

Explored three content depth levels: (a) conceptual only, (b) conceptual + illustrative data snapshot, (c) full evidence panel. Chose **(b)** — substantive enough to build credibility without overwhelming a prospect conversation. Architected so (c) can be added later via expandable detail toggles.

Explored two narrative framings: "trap" (provocative) and "test" (authoritative). Chose a **blend** — trap name as the hook, test framing as the proof. Example: "The Modifier Trap — Can your data vendor actually separate professional and technical components?"

## Key Decisions

- **Format:** Both interactive HTML and static PDF from one file
- **Content depth:** Option (b) now, expandable to (c) later
- **Narrative:** Blended trap-hook + test-proof structure
- **Branding:** Starset/Third Horizon (skeleton first, brand applied later)
- **Tech:** Single self-contained HTML file, vanilla HTML/CSS/JS
- **Audience:** BD team for prospects, Peter at MMA for their knowledge library
